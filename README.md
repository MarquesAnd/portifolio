# marquesand.github.io

Personal portfolio of André Marques. Bilingual (EN/PT), static, no build step.

- `index.html`: the site
- `assets/`: styles, scripts, bilingual project texts (`content.js`), images
- `demos/<app>/`: static demo screens of each app with fictional data (`screens.json` lists them)
- `demos/manifest.js`: list of demo screens loaded by the site (regenerate if you add screens)
- `github-profile/README.md`: copy it into a repo named `MarquesAnd` to get a profile README

**Photo:** save it as `assets/img/andre.jpg` and uncomment the `<img>` line inside `#photo` in `index.html`.

**Publish:** push to a public repo named `MarquesAnd.github.io` → Settings → Pages → Deploy from branch `main` / root.
